# GPU 对 CPU：方法与实测结果

## 样本和执行控制

本源码发布版只有一个 GPU 实现。CPU 使用同一程序关闭 Metal；GPU 启用 Metal、ownership 和限定布局的非局域 hook。设备为 Apple M5 Max，128 GiB 统一内存；VASP 6.4.1、std 复数、单 MPI rank、单 BLAS 线程、Gamma-centered 1×1×1 采样。CPU 参考是受控的单 BLAS 线程路线，不是优化后的全线程 CPU 对照。

A 数据集含七个完整的 20–128 原子体系。B 数据集包含 20 体系实验全部 20 个已完成体系。只纳入全部路线正常退出、输入/数值/完整 SCF 门通过且计时有效的体系；快照时所有符合条件者全部纳入。该实验已无未完成体系。公开总体为 27 个结构、216 个 CPU/GPU 进程（含每路线一次预热）、162 个正式计时样本和 108 个含预热的 GPU 对 CPU 对照。计数只描述公开 CPU/GPU 子集。

两个数据集代表不同输入总体，不是不同软件版本。组成、自旋、截断能和能带数同时变化，不能合并为只由原子数决定的规模规律。每路线一次预热、三次正式独立进程。计时审核检查拥有进程身份、暂停/时钟事件及原生竞争任务。已确认的正常拥有进程退出事件由保留的只读证据解决；未知事件不静默接受。原状态和私有证据保留，未为改善图片重算或放宽容差。

## 数值一致性

108 个对照全部通过原输入、数值、符合条件 GPU 和完整电子序列门。含预热最大差异：总能量 1.00000079328311e-08 eV；力分量 7.0000000001319e-08 eV/Å；力向量均方根误差 3.77491721729444e-08 eV/Å；应力分量 4.52000000006336e-06 kbar；完整自洽场（SCF）能量序列 1.97000076695986e-07 eV。每对 SCF 迭代数相同。图片每结构显示三次正式对照；预热记录保留在数据中。

对原子 `i`，`ΔF_i = F_i^GPU − F_i^CPU`。向量 RMSE 为 `sqrt(mean_i(sum_component(ΔF_i²)))`；分量 RMSE 对全部 3N 分量平均。最大向量范数不同于最大分量差。每原子能量差为总能量差除以原子数。精确打印零值完整保留；这些值衡量指定输入的软件一致性，不是物理密度泛函精度、未见输入或普遍误差界。

## 条件和实现范围

`benchmarks/data/input-settings.json` 列出每个 INCAR 设置、k 点网格及输入哈希，包括 POTCAR 哈希但不分发 PAW 数据。典型控制为 Accurate 精度、Normal SCF、无实空间投影、无对称性、静态 fresh start、EDIFF=1e-6；截断能、能带数、展宽和自旋依体系确定。这些是基准假设，不是一般收敛建议。每对 CPU/GPU 输入和算法一致。

非局域力/应力 GPU 投影目前限于 std 复数、单 rank/k 点/自旋/spinor、非螺旋布局。Ni20、Fe24、Co32 使用 ISPIN=2，非局域投影回退 CPU，其他符合条件的 FFT、线性代数等内核仍在 GPU 执行。这些体系投影计数为零不是计算失败或整体 GPU 无工作。实际 Gamma/SOC 回退测试另见 `release-validation.json`。

## 资源和计时口径

RSS 是每两秒采样的原生进程常驻集大小；部分很短的计算没有 RSS 样本，保留 NA 并不绘制。Metal 峰值在项目跟踪的资源分配时观察，不是驱动整体显存或全部统一内存。非局域工作区计划值是单算子的边界。host 事务暂存未测量（NA）。这些口径重叠不能相加，排除其他应用及未采到的驱动/进程瞬峰。

波基底导入是累计逻辑 ABI 字节，复用计数只针对该路径，不是物理总线传输、全部通信或峰值存储。公开遥测只展示当前路线，不使用历史版本基线。源码阶段 wall time 含等待，LOOP/STRESS 父阶段包含子阶段；API wall、进程 CPU、GPU command、等待和转换计时也重叠。图不堆叠这些值，不把 command 时长等同于硬件占用率。

## 可复现公开证据

`measured.json` 提供每个结构、路线汇总、精度、资源、计时、来源及口径；CSV 暴露全部所选路线进程和正式样本。中性证据 ID 将每个派生值关联到保留证据的 SHA256 与 JSON/VTIME 定位，私有路径映射由维护者保留。包内排除授权源码/PAW、二进制和私有日志。派生数据不能替代 VASP 授权或独立复现私有输入。

安装 `requirements-figures.txt` 后运行 `python3 benchmarks/plot_release.py`。[图片索引](FIGURES.md)给出七组图的论点和双语图注。PNG 为 400 dpi、PDF 嵌入字体、SVG 保留文字。图片/数据哈希及 180 mm 设计规格见 `docs/assets/figure-manifest.json` 和 `figure-specs.json`。

公开后端/源码适配器保持不变，源码重建已核对。公开安装器的后端编译成功，原生校验有 33/34 项后端测试通过，非局域 ABI 生命周期测试以 SIGTRAP 异常退出；尚未执行 VASP std/gam/ncl 构建及安装器烟测。这一独立安装器验证门仍失败；本次图表更新没有修复内核或重算数据。见 `release-validation.json`；完整 SCF 常驻、剩余宽索引、ILP64、分布式及其他投影布局仍开放。
